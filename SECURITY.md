# Security Policy

## Reporting a Vulnerability

If you believe you have found a security vulnerability in this repository, do **not** open a public GitHub issue.

Please report it privately using one of these channels:

- GitHub Security reporting for this repository
- Email: [security@hellotars.com](mailto:security@hellotars.com)


Include the following when possible:

- A clear description of the issue
- Steps to reproduce
- Affected package, file, route, or API surface
- Impact assessment
- Proof of concept, logs, or screenshots if relevant
- Any suggested remediation

## What to Expect

- We will review the report and determine whether it is a valid security issue.
- We may contact you for additional details or reproduction help.
- We will aim to acknowledge receipt within a reasonable time.

## Supported Versions

This repository does not currently maintain multiple supported release lines.

Please report vulnerabilities against the latest code on the default branch unless a maintainer instructs otherwise.

## Public Disclosure

Please avoid public disclosure until the issue has been reviewed and a fix or mitigation plan has been prepared.
